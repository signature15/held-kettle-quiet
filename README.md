# held-kettle-quiet

## Purpose

A tiny Node 22 program that writes a quiet still-life sentence to `entry.txt`, giving the reader a contained, gentle moment to notice.

## Bounty

https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory; otherwise the program writes to `./output`.
